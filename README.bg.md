# Screenshot Styler

Screenshot Styler е базиран в браузър инструмент за преобразуване на обикновени скриншотове в полирани визуали.
Качете изображение (или вземете съдържание от туит), приложете предустановка + палета, настройте параметри на рамката и експортирайте готови за споделяне активи.

## Основни функции

- Локална обработка: изображенията остават във вашия браузър.
- Гъвкав вход: качване на PNG/JPG, поставяне от буфер обмена или вземане на съдържание от туит чрез oEmbed.
- Широк набор за стилизиране: градиенти, мрежи, еднотонни, шаблони, фоне с изображения, рамки на браузър/устройство и макети на карти.
- Интерфейс, осведомен за темата: тъмен/светлинен режим с постоянна предпочитание.
- Формати за експортиране: копиране на PNG в буфер обмена, изтегляне на PNG, изтегляне на 4K PNG или експортиране на SVG.
- Запазени контроли: предустановка, палета, режим на заглавна лента, съотношение на страните и превключване на анимация се съхраняват локално.

## Бърз старт

### Предварителни условия

- Node.js 18+
- npm

### Локално стартиране

```bash
npm install
npm run dev
```

Приложението се стартира на [http://localhost:5173](http://localhost:5173).

## Скриптове

- `npm run dev` - стартиране на Vite dev сървър
- `npm run build` - изграждане на production bundle
- `npm run preview` - преглед на production build
- `npm run lint` - стартиране на ESLint
- `npm run typecheck` - стартиране на TypeScript проверки
- `npm run test -- --run` - еднократно стартиране на Vitest套

## Как работи

1. Импортирайте изображение (качване/поставяне) или вземете съдържание от туит.
2. Изберете стилна предустановка и цветна палета.
3. Настройте заглавната лента, съотношението на страните и опциите за анимация.
4. Експортирайте PNG/SVG от живия SVG преглед.

## Предустановки и палети

- 25 предустановки в категориите фон, рамка и карта.
- 20+ курирани палети за тъмни, светли, живи и минималистични вида.
