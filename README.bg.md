# Screenshot Styler

Screenshot Styler е браузърен инструмент за превръщане на обикновени екранни снимки в полирани визуални елементи.
Качи изображение (или изтегли съдържание от туит), приложи наборка за стил + палитра, регулирай контролите за рамка и експортирай готови за споделяне активи.

## Основни възможности

- Обработка, чувствителна към поверителност: изображенията остават в браузъра ви.
- Гъвкав вход: качване на PNG/JPG, поставяне от буфер на обмена или изтегляне на съдържание от туит чрез oEmbed.
- Широк набор от стилове: градиенти, мрежа, еденични цветове, модели, фонови изображения, рамки на браузър/устройство и оформления на картички.
- Интерфейс, осведомен за темата: тъмен/светъл режим с запазена предпочитание.
- Формати на експорт: копирай PNG в буфер на обмена, изтегли PNG, изтегли 4K PNG или експортирай SVG.
- Запазени управления: наборката за стил, палитра, режим на лентата на заглавието, съотношение на страните и превключвател на анимацията се запазват локално.

## Бързо начало

### Предварителни изисквания

- Node.js 18+
- npm

### Локално стартиране

```bash
npm install
npm run dev
```

Приложението работи на [http://localhost:5173](http://localhost:5173).

## Скриптове

- `npm run dev` - стартирай Vite dev сървър
- `npm run build` - постави production bundle
- `npm run preview` - преглед на production build
- `npm run lint` - стартирай ESLint
- `npm run typecheck` - стартирай TypeScript проверки
- `npm run test -- --run` - стартирай Vitest набор един път

## Как работи

1. Импортирай изображение (качване/поставяне) или изтегли съдържание от туит.
2. Избери наборка за стил и цветна палитра.
3. Регулирай лентата на заглавието, съотношението на страните и опциите за анимация.
4. Експортирай PNG/SVG от живия SVG преглед.

## Наборки за стил и палитри

- 25 наборки за стил в категориите фон, рамка и картичка.
- 20+ подбрани палитри за тъмни, светли, ярки и минималистични изгледи.
